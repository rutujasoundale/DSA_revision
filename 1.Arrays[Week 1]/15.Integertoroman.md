```java
class Solution {
    public String intToRoman(int num) {
        // We must write Roman numeral values in descending order
        final int[] values={1000 , 900 , 500 ,400 ,100 ,90,50,40,10,9,5,4,1};
        //Corresponding Roman numeral symbols
        final String[] symbols = {"M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"};
        //Stores the final Roman numeral in stringbuilder
        StringBuilder sb =new StringBuilder();
        //Traverse all Roman numeral values from largest to smallest
        for(int i=0;i<values.length;i++){
            //stop when number iss covered
            if(num==0)
            break;
            //Untill we got the ans we must keep subtracting the num 
            while(num>=values[i]){
                //Append corresponding roman symbol to present value  when the num is greater than present value of integer 
                sb.append(symbols[i]);
                num-=values[i];
            }
        }
        //return the ans 
        return sb.toString();
    }
}
```
Short intuition
Start with the largest Roman value.
If it can fit into the number, append its symbol and subtract its value.
Repeat until it no longer fits.
Move to the next smaller value.
Continue until the number becomes 0.

This is a greedy algorithm, because at every step you choose the largest possible Roman numeral. Time complexity is O(1) since there are only 13 Roman numeral values.
Why Greedy Works

Always subtract the largest possible Roman value.

Example: 3749

Time Complexity

There are only 13 Roman denominations, so the loop runs over a constant-size array.

Time: O(1) (or O(13))
Space: O(1) (excluding the output string)
