💡 Approach
Initialize ans = 0.
Traverse the Roman numeral from right to left.
Convert the current Roman character into its integer value.
If 4 * currentValue < ans, subtract it from the answer.
Otherwise, add it.
Return the final answer.
```
class Solution {
    public int romanToInt(String s) {
        int ans=0;
        int num=0;

        for(int i=s.length()-1;i>=0;i--){
            switch (s.charAt(i)){
                case 'I':
                    num = 1;
                    break;
                case 'V':
                    num = 5;
                    break;
                case 'X':
                    num = 10;
                    break;
                case 'L':
                    num =50;
                    break;
                case 'C':
                    num = 100;
                    break;
                case 'D':
                    num=500;
                    break;
                case 'M':
                    num = 1000;
                    break;
                            

            }
            if(4*num<ans)
                ans-= num;
            else
                ans += num;

        }
        return ans;
    }
}
```

⏱️ Complexity Analysis
Time Complexity: O(n)

We traverse the string exactly once.
Space Complexity: O(1)

Only a few integer variables are used.
🌟 Key Takeaways
Traverse the Roman numeral from right to left.
Convert each Roman character to its integer value.
Use the condition 4 * value < ans to determine whether to subtract or add.
Achieves O(n) time complexity with O(1) extra space.
